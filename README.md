# Portafolio — Iván Ricardo Díaz C.

Landing page de portafolio profesional con estilo tech/QA (tema oscuro, terminal).

## Stack

- **Next.js 15** + React 19
- **Tailwind CSS** + Framer Motion
- **TypeScript**

## Secciones

1. Hero con efecto typewriter
2. Sobre mí
3. Habilidades (grid por categoría)
4. Experiencia (timeline)
5. Educación
6. Contacto (Email, WhatsApp, LinkedIn)

## Instalación

```bash
npm install
npm run dev
```

Abrir [http://localhost:3000](http://localhost:3000) en el navegador.

## Despliegue

Compatible con Vercel, Netlify u otro hosting de Next.js.
